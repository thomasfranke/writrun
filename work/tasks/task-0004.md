# Name task and spec files by id and subject

**References:** [technical/README.md#task-schema](../../docs/technical/README.md#task-schema) · [spec-0001](../specs/spec-0001.md)

The docs now name a queue file `task-NNNN-<subject>.md` /
`spec-NNNN-<subject>.md` — a four-digit id plus an extremely short echo
of the title — and the machinery still writes and expects the bare-id
shape. Bring the writer and every reader up to the rule, so a directory
listing of the queue reads as a summary of it.

The four queue files born in this change predate the slug on purpose: a
queue file is never renamed, so they stay the last of the old shape.
