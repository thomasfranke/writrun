# Reflect every task a pull request carries

**References:** [product/stage-2-pull-requests/review.md](../../docs/product/stage-2-pull-requests/review.md) · [spec-0002](../specs/spec-0002.md)

A pull request may now carry several tasks, each tagged `[TASK-NNNN]` in
its title, and the machinery still resolves a PR to a single task
through the branch-name marker. Everything that follows a PR's work —
the mirror that tracks review, the in-flight report — must see the
whole tagged set, falling back to the branch marker when no tag is
present.
