# Title mirror Issues by task tag

A mirror Issue is now titled `[TASK-NNNN] <task title>` — the same tag a
pull request title carries — and the machinery still mints
`task-NNNN — <title>` and finds a mirror by that old prefix. Bring the
minting and every title lookup to the tag form, and retitle the mirrors
that already exist.
