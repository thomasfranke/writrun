# Label a proposed task apart from a queued one

The mirror gives `status:pending` to two different things: a task an open
pull request merely proposes, and a task already in the queue whose spec
is not approved yet. The label's own description only describes the
second, so it reads as false for half the issues carrying it.

Give the first state `status:proposed`, and let `status:pending` mean
what its description already claims.
